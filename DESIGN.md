# Football AI — espace d'analyse

Surface : `examples/soccer/streamlit_app.py`. Mode Operate.
Extension de l'identité sombre/verte existante, examinée dans l'application déployée.

- Fond #0E1117, panneau #161B22, texte #E6EDF3, texte secondaire #A7B4C4.
- Vert #22C55E pour la sélection et les actions. Rose #FF1493 pour A et cyan #00BFFF pour B,
  accompagnés de libellés. Gris pour l'inconnu. Ces couleurs correspondent aux vidéos.
- Une famille sans serif système ; chiffres tabulaires. Hiérarchie compacte de titres.
- Navigation latérale par tâche : extraits / import. Les réglages d'inférence restent dans l'import.
- Premier écran : extrait, durée, lecteur vidéo et terrain synchronisés. Les indicateurs
  apparaissent sous le lecteur, avec périmètre et inconnues. Pas de héros promotionnel.
- Exploration : Tactique, Joueurs, Événements, Fiabilité. Le filtre temporel recalcule les mesures.
- Cartes du terrain et tracés cohérents en mètres ; positions hors champ non inventées.
- Bureau : vidéo et terrain côte à côte. Mobile : lecture puis terrain, contrôles accessibles.
- États explicites pour géométrie non calibrée, ballon absent, peu de joueurs et absence de passes.
- Pas de téléchargement de modèles pour consulter les exemples ; données et vidéo précalculées.

Vérification : une passe regroupée bureau/mobile, correction groupée, puis confirmation.
